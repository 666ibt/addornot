# Vis — Telegram-бот ежедневной рассылки

Каждый день присылает подписчикам подборку, которая раскрывается пошагово:

1. 🌍 **Новости** — одно сообщение (твой текст). Под ним кнопка → отрывок дня.
2. 📖 **Книжный отрывок** — под ним две кнопки:
   - ⬇️ **Скачать полную версию** — файл книги (EPUB для приложения **Books** на iOS);
   - 👤 **Перейти к личности дня**.
3. 👤 **Личность дня** — отправляется **Word-файлом** (.docx).

Контент бот **не генерирует** — он берёт его из JSON-файлов в `data/`, которые ты
пополняешь. Нужен только токен Telegram-бота, без внешних API и оплаты.

## Стек

- **Python 3.11+ / aiogram 3** — бот;
- **APScheduler** — ежедневная рассылка;
- **SQLite (aiosqlite)** — подписчики, история, подборка дня;
- **python-docx** — генерация Word-файла личности.

## Кто что может

- **Обычный пользователь:** `/start` (подписка + время рассылки), `/stop`.
  Контент приходит только в ежедневной рассылке — раскрывается кнопками.
- **Админ** (`ADMIN_IDS` в `.env`): дополнительно `/today` — прислать текущую
  подборку себе для проверки.

## Как наполнять контент

Файлы в `data/`. Бот берёт **следующую ещё не отправленную** запись каждой
категории, так что можно держать запас на несколько дней.

**`data/news.json`** — твой готовый текст новостей:
```json
[
  { "text": "🌍 <b>Главное за день</b>\n\n• Новость 1\n• Новость 2" }
]
```

**`data/books.json`**:
```json
[
  {
    "title": "Старик и море",
    "author": "Эрнест Хемингуэй",
    "excerpt": "Текст отрывка (до одной страницы)...",
    "hook": "Крючок (необязательно)",
    "full_file": "books_files/starik-i-more.epub"
  }
]
```
Файлы книг клади в `data/books_files/` (см. README там). **EPUB** — родной формат
для приложения Books на iOS. Если `full_file` пустой или файла нет — кнопка
скачивания не показывается.

**`data/persons.json`**:
```json
[
  {
    "name": "Никола Тесла",
    "years": "1856–1943",
    "bio": "Кто это и чем важен...",
    "achievements": ["Достижение 1", "Достижение 2"],
    "quotes": ["Цитата 1", "Цитата 2"]
  }
]
```
Из этой записи бот собирает .docx и отправляет файлом.

В текстах можно использовать HTML-теги `<b>` и `<i>`. Поле `"id"` задаёт ключ
антидублей вручную. Бот не повторяет уже отправленные записи (таблица `sent_items`).

## Запуск на своём ПК

```bash
cd vis_bot
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env        # впиши BOT_TOKEN и ADMIN_IDS
python bot.py
```

Свой Telegram ID для `ADMIN_IDS` узнаёшь у [@userinfobot](https://t.me/userinfobot).
Дальше боту: `/start`, а для проверки подборки (как админ) — `/today`.

## Когда приходит рассылка

По умолчанию каждый день в 9:00 по Москве (`DAILY_HOUR`, `DAILY_MINUTE`,
`TIMEZONE` в `.env`). Рассылка идёт, только пока запущен `bot.py`.

## Постоянная работа (необязательно)

```bash
docker build -t vis-bot .
docker run -d --restart always --env-file .env -v "$PWD/data:/app/data" --name vis vis-bot
```

## Структура

```
vis_bot/
├── bot.py               # точка входа
├── config.py            # настройки из .env
├── data/                # контент (наполняешь сам)
│   ├── news.json
│   ├── books.json
│   ├── persons.json
│   └── books_files/     # файлы полных версий книг (EPUB)
└── app/
    ├── db.py            # подписчики, история, подборка дня
    ├── content_store.py # чтение/рендеринг контента из файлов
    ├── docgen.py        # сборка .docx для личности
    ├── digest.py        # подборка дня, клавиатуры, новостное сообщение
    ├── handlers.py      # команды и кнопки
    └── scheduler.py     # ежедневная рассылка
```
