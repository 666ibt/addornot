# Vis — Telegram-бот ежедневной рассылки

Каждый день присылает подписчикам три вещи:

1. 🌍 **Главные мировые новости** — только крупные, глобально значимые события (через веб-поиск, чтобы быть свежими).
2. 📖 **Книжный отрывок дня** — один цепляющий фрагмент (до одной страницы) + кнопка «Где прочитать целиком».
3. 👤 **Заметку о выдающейся личности** — краткая справка, достижения и пара цитат.

Весь контент — на русском, генерируется через Claude API (`claude-opus-4-8`).
Источники — интернет (статьи, материалы), книги и популярные YouTube-разборы
(Минаев Live и т.п.). **Википедия не используется** (домены заблокированы в поиске).

### Источники для заметки о личности

Заметка о личности может строиться **на основе субтитров свежего ролика** с
указанных тобой YouTube-каналов:

- список свежих видео берётся из публичной RSS-ленты канала (без платного API);
- субтитры — через `youtube-transcript-api`;
- Claude определяет центральную личность ролика и пишет заметку, **сверяя факты и
  цитаты веб-поиском** (транскрипт — авторасшифровка, в нём бывают ошибки).

Каналы указываются в `.env` (`YOUTUBE_CHANNEL_IDS`, ID вида `UC...`, через запятую).
Если каналы не заданы или у роликов нет субтитров — заметка строится по веб-поиску.

### Антидубли

Бот помнит недавно отправленные книги и личности (таблица `sent_items`) и просит
Claude не повторять их. Подборка для всех подписчиков генерируется **один раз за
рассылку** — это дешевле по токенам и исключает дубли. Новости не дедуплицируются:
они и так привязаны ко дню.

## Стек

- **Python 3.12 + aiogram 3** — Telegram-бот;
- **Anthropic API** — генерация/фильтрация контента;
- **APScheduler** — ежедневная рассылка по расписанию;
- **SQLite (aiosqlite)** — список подписчиков.

## Запуск на своём ПК

1. Установи Python 3.11+.
2. Поставь зависимости:
   ```bash
   cd vis_bot
   python -m venv .venv
   source .venv/bin/activate        # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Получи токены:
   - **BOT_TOKEN** — у [@BotFather](https://t.me/BotFather) (`/newbot`);
   - **ANTHROPIC_API_KEY** — в [консоли Anthropic](https://console.anthropic.com/).
4. Создай `.env`:
   ```bash
   cp .env.example .env
   # открой .env и впиши BOT_TOKEN и ANTHROPIC_API_KEY
   ```
5. Запусти:
   ```bash
   python bot.py
   ```

Бот работает, пока запущен этот процесс. Напиши боту `/start`, чтобы подписаться,
и `/today`, чтобы сразу получить подборку и проверить, что всё работает.

## Команды

| Команда  | Что делает                                   |
|----------|----------------------------------------------|
| `/start` | подписаться на рассылку                       |
| `/today` | прислать сегодняшнюю подборку прямо сейчас     |
| `/stop`  | отписаться                                    |

## Когда приходит рассылка

По умолчанию — каждый день в 9:00 по Москве. Меняется в `.env`
(`DAILY_HOUR`, `DAILY_MINUTE`, `TIMEZONE`).

⚠️ Рассылка идёт, только пока запущен `bot.py`. На своём ПК это означает, что
компьютер должен быть включён и иметь интернет в момент отправки.

## Чтобы бот не падал (необязательно)

- **Linux/Mac:** запусти через `systemd` или `tmux`/`screen`.
- **Docker** (одинаково на ПК, малинке, VPS):
  ```bash
  docker build -t vis-bot .
  docker run -d --restart always --env-file .env --name vis vis-bot
  ```

## Структура

```
vis_bot/
├── bot.py               # точка входа
├── config.py            # чтение настроек из .env
├── requirements.txt
├── Dockerfile           # на будущее
├── .env.example
└── app/
    ├── db.py            # подписчики + история контента (SQLite)
    ├── digest.py        # сборка подборки (один раз) + отправка, антидубли
    ├── handlers.py      # команды и кнопки
    ├── scheduler.py     # ежедневная рассылка
    └── content/
        ├── claude_client.py  # обёртка над Anthropic API (веб-поиск, без Википедии)
        ├── news.py           # новости (с веб-поиском)
        ├── book.py           # книжный отрывок + «где прочитать»
        ├── person.py         # заметка о личности (по YouTube-ролику или веб-поиску)
        └── youtube.py        # транскрипты свежих роликов с каналов
```
