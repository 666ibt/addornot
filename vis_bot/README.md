# Vis — Telegram-бот ежедневной рассылки

Каждый день присылает подписчикам три вещи:

1. 🌍 **Главные новости**
2. 📖 **Книжный отрывок** + кнопка «Где прочитать целиком»
3. 👤 **Заметку о выдающейся личности** — справка, достижения, цитаты

Контент бот **не генерирует сам** — он берёт его из простых JSON-файлов, которые
ты пополняешь. Никаких внешних API и оплаты: нужен только токен Telegram-бота.

## Стек

- **Python 3.11+ / aiogram 3** — Telegram-бот;
- **APScheduler** — ежедневная рассылка по расписанию;
- **SQLite (aiosqlite)** — подписчики и история отправленного.

## Как наполнять контент

Контент лежит в папке `data/` в трёх файлах. Просто добавляй туда новые записи —
бот берёт **следующую ещё не отправленную** запись каждой категории. Можно
держать запас на несколько дней вперёд.

**`data/news.json`**
```json
[
  { "items": ["Первая новость", "Вторая новость"] }
]
```

**`data/books.json`**
```json
[
  {
    "title": "Старик и море",
    "author": "Эрнест Хемингуэй",
    "excerpt": "Текст отрывка (до одной страницы)...",
    "hook": "Одно предложение-крючок (необязательно)",
    "where_to_read": "Текст для кнопки «Где прочитать целиком» (необязательно)"
  }
]
```

**`data/persons.json`**
```json
[
  {
    "name": "Никола Тесла",
    "years": "1856–1943",
    "bio": "Кто это и чем важен...",
    "achievements": ["Достижение 1", "Достижение 2"],
    "quotes": ["Цитата 1", "Цитата 2"]
  }
]
```

В текстах можно использовать HTML-теги `<b>` (жирный) и `<i>` (курсив).
Необязательное поле `"id"` в любой записи задаёт ключ для антидублей вручную.

### Антидубли

Бот помнит, какие записи уже отправлял (таблица `sent_items`), и не повторяет их.
Подборка для всех подписчиков собирается **один раз за рассылку**.

## Запуск на своём ПК

1. Установи Python 3.11+.
2. Поставь зависимости:
   ```bash
   cd vis_bot
   python -m venv .venv
   source .venv/bin/activate        # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Получи токен бота у [@BotFather](https://t.me/BotFather) (`/newbot`).
4. Создай `.env`:
   ```bash
   cp .env.example .env
   # открой .env и впиши BOT_TOKEN
   ```
5. Запусти:
   ```bash
   python bot.py
   ```

Напиши боту `/start`, чтобы подписаться, и `/today`, чтобы сразу получить
текущую подборку и проверить, что всё работает.

## Команды

| Команда  | Что делает                                   |
|----------|----------------------------------------------|
| `/start` | подписаться на рассылку                       |
| `/today` | прислать текущую подборку прямо сейчас         |
| `/stop`  | отписаться                                    |

## Когда приходит рассылка

По умолчанию — каждый день в 9:00 по Москве. Меняется в `.env`
(`DAILY_HOUR`, `DAILY_MINUTE`, `TIMEZONE`).

⚠️ Рассылка идёт, только пока запущен `bot.py`. На своём ПК это значит, что
компьютер должен быть включён и иметь интернет в момент отправки.

## Чтобы бот не падал (необязательно)

- **Linux/Mac:** запусти через `systemd` или `tmux`/`screen`.
- **Docker** (одинаково на ПК, малинке, VPS):
  ```bash
  docker build -t vis-bot .
  docker run -d --restart always --env-file .env -v "$PWD/data:/app/data" --name vis vis-bot
  ```

## Структура

```
vis_bot/
├── bot.py               # точка входа
├── config.py            # чтение настроек из .env
├── requirements.txt
├── Dockerfile
├── .env.example
├── data/                # контент (наполняешь сам)
│   ├── news.json
│   ├── books.json
│   └── persons.json
└── app/
    ├── db.py            # подписчики + история контента (SQLite)
    ├── content_store.py # чтение и рендеринг контента из файлов
    ├── digest.py        # сборка подборки + отправка, антидубли
    ├── handlers.py      # команды и кнопки
    └── scheduler.py     # ежедневная рассылка
```
