# Файлы полных версий книг

Сюда кладёшь файлы книг (рекомендуется **EPUB** — родной формат для приложения
**Books** на iOS). В записи книги в `data/books.json` укажи путь относительно
папки `data`, например:

```json
{ "title": "...", "author": "...", "excerpt": "...",
  "full_file": "books_files/starik-i-more.epub" }
```

Если `full_file` пустой или файла нет — кнопка «Скачать полную версию» не
показывается. Загружай только книги, на которые у тебя есть права
(общественное достояние или твои легальные копии).
