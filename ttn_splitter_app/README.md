# TTN Waybill Splitter — десктоп-приложение

Разбивает многостраничные PDF-сканы топливных накладных (ТТН / ГСМ) на
**по одному PDF на страницу** и называет каждый файл по номеру накладной и
договора в виде `{накладная}_{договор}.pdf` (например `37_SGN-2-25.pdf`).

Поддерживаются два формата:

- **Товарно-транспортная накладная** (типовая форма № 1-т);
- **«Накладная на отпуск материалов»** Ферганского НПЗ (ФНПЗ).

Номер договора начинается с `SGN` (например `SGN-158/25`, `SGN-59/26-P`);
для внутренних перемещений вместо номера подставляется `Перемещение`.

Это настольная реализация навыка `/ttn-waybill-splitter`.

---

## Как это работает

1. **Растеризация** — каждая страница PDF превращается в изображение
   (`pdf-to-img`).
2. **Гибридное распознавание**:
   - сначала локальный **OCR** (`tesseract.js`, русский + английский) и разбор
     номеров регулярными выражениями (`src/main/extract.js`);
   - если уверенность низкая — **резервное распознавание через Claude**
     (vision-модель) по изображению страницы (`src/main/ai.js`);
   - всё это можно **вручную поправить** в интерфейсе перед сохранением.
3. **Разбивка** — исходная страница копируется в отдельный PDF **без потери
   качества** (`pdf-lib`, не сохраняем растровую картинку) и получает имя
   `{накладная}_{договор}.pdf`. Совпадающие имена автоматически получают
   суффиксы `_2`, `_3`, …

## Стек

- **Electron** — десктоп-оболочка (Windows / macOS / Linux);
- **pdf-lib** — разбивка PDF постранично;
- **pdf-to-img** — рендер страниц в изображения;
- **tesseract.js** — локальный OCR (офлайн);
- **Claude API** — резервное распознавание сложных сканов;
- **electron-store** — локальные настройки (API-ключ хранится только на
  вашем компьютере).

## Запуск в разработке

```bash
cd ttn_splitter_app
npm install
npm start
```

## Сборка установщика

```bash
npm run dist        # для текущей ОС
npm run dist:win    # Windows (.exe / NSIS)
npm run dist:mac    # macOS (.dmg)
npm run dist:linux  # Linux (AppImage)
```

Готовые файлы появятся в папке `release/`.

## Настройка AI-распознавания (необязательно, но рекомендуется)

Откройте **⚙ Настройки** в приложении и вставьте свой **Anthropic API-ключ**.
Там же можно выбрать модель и когда подключать AI:

- *только при низкой уверенности* (по умолчанию, дешевле);
- *при низкой и средней уверенности*;
- *никогда* — полностью офлайн, только локальный OCR.

Ключ хранится локально через `electron-store` и **никогда не попадает в
репозиторий**.

## Офлайн-OCR

По умолчанию `tesseract.js` при первом запуске скачивает языковые данные.
Для полностью офлайн-работы положите файлы `rus.traineddata.gz` и
`eng.traineddata.gz` в папку `tessdata/` рядом с приложением — они будут
использованы автоматически.

## Тесты

Ядро разбора номеров (`src/main/extract.js`) покрыто юнит-тестами и не
зависит от Electron:

```bash
npm test
```

│       ├── renderer.js
│       └── styles.css

    └── extract.test.js
