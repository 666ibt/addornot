# Contract generation — template notes (from the real .docx archive)

Source samples (user's real contracts), analysed for the generator:

## Документы на выходе
- **договор** — узбекский (кириллица). SEGNUM и SEG TASCO — разные шаблоны.
- **лист согласования** — русский. **Только SEG TASCO** (для SEGNUM не создаётся).
- **служебная записка** — русский. Обе компании.

## Структура папки (как в архиве)
`<SEGNUM|SEG TASCO>/<seq>. Договор № <номер> от <дата> <Контрагент>/`
Внутри: `Договор № …`, `Лист согласований к Договору № …` (только SEG TASCO),
`СЛУЖЕБНАЯ ЗАПИСКА к Договору № …`.

## Переменные места в договоре (пример SGN-225)
- № договора: `SGN-225/26` (в шапке `… - сонли ШАРТНОМА`).
- дата: `«06» июль 2026 й.` (месяц узбекскими словами).
- вводный абзац: наименование контрагента, форма (`ҚК МЧЖ` / `МЧЖ`),
  основание (`ўз Устави асосида` = устав / `ишончнома асосида` = доверенность),
  должность и ФИО директора (`бош директор Смирнов Т.В.`).
- таблица товара: наименование, `тн`, кол-во, цена за тн, сумма.
- итог (`Жами:`) и п. 2.2: сумма цифрами + **прописью узбекской кириллицей**
  в скобках (без «сўм» внутри скобок; «сўм» после скобок).
- **акциз** (2 места): `акциз солиғи билан кўрсатилган` (с) /
  `акциз солиғисиз кўрсатилган` (без).
- пункт отгрузки (п. 3.1 — терминал/омбор).
- блок реквизитов контрагента (правая колонка, «Харидор»):
  Манзил, Банк, ҳ/р, `МФО … СТИР …`, `ИФАК …` (не всегда), `РКП НДС …`, Телефон,
  подпись `____ ФИО`.

## Поля контрагента, нужные шаблону
название, форма (ҚК МЧЖ/МЧЖ/…), директор + должность, основание (устав/доверенность),
адрес, банк, р/с (ҳ/р), МФО, ИНН (СТИР), ИФУТ/ОКЭД (опц.), РКП НДС, телефон.

## Подход к генерации
Runs в Word сильно фрагментированы — прямая замена подстроки не работает.
Использовать span-замену по объединённому тексту абзаца с переписыванием
минимального диапазона runs (см. будущий src/main/docx.js). Один канонический
шаблон .docx на компанию; заменяются известные базовые значения образца.

## Адресат служебной записки (отложенный вопрос)
Встречаются: «Директору ООО SEGNUM Закирову Ш.Ш.», «Исполнительному директору
ООО SEG TASCO Закирову Ш.Ш.», «Генеральному директору ООО SEG TASCO
Шерназарову У.Э.», «Заместителю управляющего директора …». Выбор адресата для
SEG TASCO — уточнить у пользователя после остальных задач.
